# Sample callers

Who to pretend to be when you try the agent. Invented sample data for trying the agent. Every person, number and address here is made up. The page shows this list only while the data folder is the bundled sample data it was generated from.

The agent treats **2026-03-05** as today, so the deadlines below are counted from that date. To use one: open the page, expand "Sample callers", press a message button (it fills the message box, it does not send), then send it. Or paste a message yourself.

This file is generated by `scripts/sample_callers.py` from the files in `data/starter/`; do not edit it.
